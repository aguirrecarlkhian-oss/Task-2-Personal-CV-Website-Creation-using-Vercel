# Personal CV Website

A responsive personal curriculum vitae (CV) website that presents my profile, education, skills, projects, experience, and achievements. It was built for the IT415 – Application Development and Emerging Technologies course and serves as the foundation of my professional online portfolio.

## Technologies Used

- **HTML5** for the page structure and content
- **CSS3** for the layout, design, dark mode, and animations (Flexbox, Grid, CSS variables, media queries)
- **JavaScript (vanilla)** for the mobile menu, scroll animations, skill bars, dark mode, and printing
- **Git and GitHub** for version control
- **Vercel** for deployment

## Features

- **Complete CV sections:** Home, About (personal information, goals, career objective), Education, Skills, Projects, Experience and Achievements, and Contact
- **Responsive design:** works on desktop, laptop, tablet, and mobile phone
- **Dark mode:** a toggle button that remembers the chosen theme
- **Animations and interactions:**
  - Scroll reveal animation for sections and cards
  - Animated skill progress bars
  - Floating cards on the home section
  - Hover effects on cards, buttons, and links
  - Smooth scrolling and active navigation highlight
- **Project cards** with a screenshot preview, technologies used, and GitHub link
- **Social links** with clickable GitHub, Facebook, and Email icons
- **Print / Save CV** button that uses the browser's print function

## Project Structure

```
personal-cv/
├── index.html      # Page content, styles (CSS), and scripts (JavaScript)
├── *.jpg / *.png   # Profile picture and project screenshots
└── README.md       # Project documentation
```

The CSS and JavaScript are written inside `index.html` so the whole website is contained in one file.

## How to Run Locally

1. Clone the repository:
   ```
   git clone https://github.com/aguirrecarlkhian-oss/personal-cv.git
   ```
2. Open the folder.
3. Open `index.html` in any web browser.

No installation or build step is needed.

## Deployment

The website is deployed on Vercel. Every push to the `main` branch of this repository updates the live website.
